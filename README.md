Leonida Ledger — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5. Every trophy with its official name, description and grade, a guide in this guide's own words that cites its sources, a checklist saved in the browser with export and import, kind and grade filters, a spoiler setting that hides story trophies until they are earned, a roadmap to the platinum, and the one possibly missable trophy flagged.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network needed — every file the page loads lives under app/.
